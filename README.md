FORMA — сайт мебельной мастерской и мини-CRM
Демонстрационный проект сайта мастерской реставрации и обновления мебели с интерфейсом собственной системы управления заказами.
Возможности
- Адаптивный одностраничный сайт: услуги, галерея «До и после», этапы работы, ориентировочные цены, FAQ и контакты.
- Форма предварительной оценки мебели по фотографии (интерфейс).
- Отдельная CRM-панель: карточки заказов, канбан по этапам, стоимость и заметки мастера.
- Подготовлена интеграция с Supabase для хранения заявок, авторизации и фотографий.
Технологии
HTML · CSS · JavaScript · Supabase (PostgreSQL, Auth, Storage) · GitHub Pages

Без обязательной подписки на конструктор сайтов.
